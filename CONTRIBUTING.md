# CONTRIBUTING

- `master` - Last stable version (5.x, compatible with Kuzzle v2 and Vue 3), published under the `latest` npm dist-tag
- `beta` - Last beta version (5.x, compatible with Kuzzle v2 and Vue 3), published under the `beta` npm dist-tag
- `4-stable` - Maintenance of version 4.x (compatible with Kuzzle v2 and Vue 2.7), published under the `vue2` npm dist-tag. Fixes only: it can release 4.7.x versions, not 4.8.0 (the `v4.8.0-vue3.1` prerelease tag is in the history of `master`)
- `1-dev`, `1-stable` - dev and stable branches for version 1.x, compatible with Kuzzle v1 and Vue 2
- `2-dev`, `2-stable` - dev and stable branches for version 2.x, compatible with Kuzzle v2 and Vue 2
